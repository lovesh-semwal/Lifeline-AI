# Lifeline-AI

LifeLine AI is a full-stack MERN web application designed to provide immediate assistance during medical emergencies. It connects users with nearby hospitals, blood donors, and an AI-powered emergency assistant while enabling quick SOS reporting with real-time location sharing.
The platform helps reduce response time during emergencies by allowing users to report incidents, locate hospitals, request blood donors, and receive AI-generated first-aid guidance.

Key Features:-

🚨 Emergency Reporting
Report emergencies with patient details, emergency type, location, and image.
Track the status of reported emergencies.
View personal emergency history.

🆘 One-Click SOS
Sends the user's current GPS location.
Creates an emergency request instantly.
Designed for fast emergency response.

🏥 Nearby Hospitals
Search and browse nearby hospitals.
View hospital information including contact details, available beds, and ratings.
Distance-based hospital listing.

🩸 Blood Donor Management
Register as a blood donor.
Search donors by blood group and city.
Display donor availability and last donation date.

🤖 LifeLine AI Assistant
Powered by the Groq API (Llama 3.3 70B model).
Answers questions related to first aid, emergencies, hospitals, and blood donation.
Provides safe emergency guidance while recommending professional medical help when necessary.

🔐 Authentication
JWT-based login and registration.
Protected routes.
User profile management.

📱 Modern Responsive UI
Built using React and Tailwind CSS.
